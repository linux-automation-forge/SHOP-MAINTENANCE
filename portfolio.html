01 — About

A bit about me

MM

I'm a Computer Science student based in Guntur, India, finishing my degree at Acharya Nagarjuna University. I came to software through bash scripts and small automation — the kind of tools that quietly save a shopkeeper ten minutes a sale, or free a teammate from a manual report. That grounding shapes everything I build: simple inputs, predictable outputs, software you can prove works.

What I build tends to live close to the system — POS and inventory systems, network reconnaissance tools, QR encoders — built from scratch, no libraries when I can avoid them. I prefer plain text over binary, files over databases when the scale allows, and code you can read end-to-end in an afternoon. My flagship project, SHOPKEEP, is a single 5,000-line bash script that runs an entire kirana store.

How I work: I write precise specs first, build with modern AI tooling, then verify everything myself — tests, audits, checksums. Shipped software must be provable. Every release runs through 41 self-tests and 167 regression rows before it touches a real register. If a feature can't be tested, it doesn't ship.
